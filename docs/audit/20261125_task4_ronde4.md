D-147 menunjukkan bahwa masalah dominan bukan kualitas data, melainkan **pergeseran distribusi** pada komoditas diatur (prediksi
naik tertinggal satu rezim). Ronde ini menguji dua tuas dari roadmap D-148: (A) fitur sadar-rezim dan (B) kalibrasi probabilitas
temporal. Protokol sama dengan D-145–D-147: evaluator C1-tuned (kolom & hyperparameter resmi), label resmi, seleksi hanya di origin
pengembangan (origin + h ≤ 2023-12-31), aturan buka test ditetapkan sebelum run (Δ macro F1 rerata h 4/h 8 ≥ +0,005, interval
berpasangan > 0 di ≥ 1 horizon, Δ ≥ 0 di horizon lain). Durasi semua run < 1 jam → dijalankan lokal (aturan Colab T4 untuk > 1 jam).

## 1. Kalibrasi probabilitas temporal (tahap 4) — tanpa latih ulang

`scripts/cal.py` → `hasil/cal_dev.csv`, `hasil/cal_dev_paired.csv`, `hasil/cal_selected.json`. Prediksi C1-tuned resmi
(`direction_tuned_preds`, C1t) disesuaikan di skala logit untuk setiap (h, origin o) hanya dengan informasi yang terealisasi pada o;
threshold tetap 0,5 untuk semua komoditas.

| Konfigurasi | Isi | Δ macro F1 dev h 4 (interval) | Δ h 8 (interval) |
|---|---|---|---|
| `INT_c_13` / `INT_c_26` | intercept per komoditas dari prediksi origin lampau (o' + h ≤ o) 13 / 26 minggu, prior N(0; 0,5²) | −0,018 (−0,039..−0,000) / −0,011 (−0,028..0,006) | **−0,037 (−0,059..−0,014)** / **−0,042 (−0,059..−0,021)** |
| `INT_g_13` / `INT_g_26` | intercept global yang sama | −0,014 (−0,028..−0,002) / −0,010 (−0,024..0,001) | −0,006 (−0,023..0,009) / −0,006 (−0,023..0,009) |
| `PRI_c_13_a` | pergeseran prior per komoditas: logit p + a·[logit π_baru − logit π_latih], π_baru = porsi naik label terealisasi 13 minggu terakhir; a = 0,5 / 1 | +0,001 (−0,010..0,014) / −0,015 (−0,033..0,005) | +0,002 (−0,015..0,019) / **−0,031 (−0,060..−0,003)** |
| `PRI_c_26_a` | sama, 26 minggu; a = 0,5 / 1 | **+0,006 (−0,003..0,017)** / +0,003 (−0,009..0,018) | **+0,008 (−0,005..0,024)** / −0,012 (−0,035..0,014) |

Terpilih di dev: `PRI_c_26_0.5` (rerata +0,007) — **tidak lolos** aturan buka test (kedua interval memuat nol) → test tidak dibuka.

Bacaan:
- Koreksi intercept dari prediksi lampau memperburuk: label baru terealisasi h minggu kemudian, jadi koreksinya mengejar rezim yang
  sudah lewat (tertinggal ≥ 1 rezim, sama dengan masalah yang ingin diperbaiki).
- Di periode pengembangan **tidak ada drift naik** pada komoditas diatur (kelebihan prediksi naik NONE +0,004 / +0,005; dev
  macro F1 base 0,656 / 0,676). Drift baru muncul 2024+, sehingga origin ≤ 2023 tidak dapat memilih koreksi untuk drift itu secara
  andal. Ini batas struktural protokol, bukan kegagalan metode: mengevaluasi koreksi drift di test sambil memilihnya di test = seleksi
  pada test.

## 2. Fitur sadar-rezim (tahap 3) — latih ulang C1-tuned

`scripts/feats_regime.py` (→ EXP/regime.parquet = tabel resmi + kolom baru; `hasil/policy_events.csv`), `scripts/r4_exp.py`,
`scripts/r4_eval.py` → `hasil/r4_dev_*.csv`. Varian `base` = C1-tuned resmi (dibangun dari tabel yang sama). 608 dtk lokal.

| Kelompok | Fitur (semua tersedia pada t) | Δ macro F1 dev h 4 (interval) | Δ h 8 (interval) | kelebihan prediksi naik diatur h 4 / h 8 (base +0,004 / +0,005) |
|---|---|---|---|---|
| `R_RB` base rate terealisasi | porsi label naik (y ≠ 0) dengan minggu label t' ∈ [t − h − K + 1, t − h]: komoditas K = 13, 26; seri K = 26 | +0,001 (−0,006..0,007) | −0,005 (−0,011..0,003) | +0,018 / +0,037 |
| `R_WK` keseimbangan arah mingguan | porsi Δp mingguan > 0 di antara Δp ≠ 0, 26 minggu (seri) dan 13/26 minggu (komoditas) | −0,003 (−0,008..0,003) | −0,004 (−0,011..0,004) | +0,017 / +0,031 |
| `R_PO` rezim kebijakan | `pol_age` (minggu sejak kebijakan konsumen terakhir yang diketahui), `pol_n104`, `ref_gap` (log p − log acuan berlaku), `ref_chg_last` | −0,004 (−0,012..0,004) | −0,008 (−0,017..0,001) | −0,007 / −0,005 |
| `R_ALL` | semua di atas | −0,003 (−0,012..0,005) | −0,009 (−0,021..0,005) | +0,004 / +0,012 |

Catatan desain:
- Tanggal kebijakan: `known_at` = tanggal paling awal di teks regulasi (ditetapkan / diundangkan / berlaku), `effective_at` =
  `start_date`. Dari 28 kejadian (komoditas × tanggal berlaku) hanya 4 yang diketahui sebelum berlaku, dengan selisih 1–4 hari
  (minyak goreng 2022-10, 2024-08, 2025-12; beras 2023-03) → fitur "diumumkan tetapi belum berlaku" (`ref_upcoming`) selalu 0 pada
  resolusi mingguan dan tidak dipakai. Baris `signed_only` memakai tanggal tanda tangan untuk keduanya.
- `regime_id` sebagai kategori tidak dipakai: rezim di test tidak pernah muncul di latih (kategori tak dikenal); umurnya diwakili
  `pol_age`.
- Acuan beras zona 2/3 untuk 2024 tidak tersedia per zona di tabel regulasi (hanya baris "Semua zona" Rp12.500 = nilai zona 1) →
  keterbatasan data (U6).
- Base rate terealisasi menaikkan prediksi naik (kelebihan +0,02..+0,04): base rate yang tertinggal h minggu memperkuat, bukan
  meredam, kelembaman rezim.

## 4. Split 2 (D-149, pasca-hoc eksploratif): pengembangan s.d. 2024

Atas keputusan Danen setelah §3. Ditetapkan sebelum run: pengembangan = origin + h ≤ 2024-12-31 (52 / 51 origin), test = origin
≥ 2025-01-01 (± 22 origin); kandidat dan aturan buka test sama dengan §1–§2. Karena hasil test 2024 C1-tuned (dan analisis drift
D-147) sudah pernah dilihat, seluruh hasil split ini berlabel **eksploratif pasca-hoc**. Skrip: `cal.py` (`SPLIT=2`), `r4_exp.py`
(`PART=dev2x` = 28 origin tambahan dengan 2023-12-31 < origin + h ≤ 2024-12-31), `r4_eval2.py` → `hasil/cal_*_s2.*`, `hasil/r4s2_*`.

Tidak ada kandidat yang lolos aturan → **test 2025+ tidak dibuka**.

**Drift dapat dihilangkan, tetapi bukan pembatas skor.** Fitur kebijakan (`R_PO`) menghapus hampir seluruh kelebihan prediksi naik
pada komoditas diatur di 2024 tanpa menaikkan macro F1. Pada baris komoditas diatur yang prediksinya diubah `R_PO` (7,5–18,8% baris;
`hasil/r4s2_dev2024_regulated_ticks.csv`), prediksi base benar ± 57% (h 4: 0,57 / 0,50 / 0,58 untuk 2–10 / < 2 / ≥ 10 tick; h 8:
0,57 / 0,60 / 0,47), sehingga membaliknya rata-rata merugikan. Kelebihan "naik" adalah bias proporsi agregat, bukan kumpulan baris
yang salah; baris yang tersentuh drift sebagian besar perubahan kecil yang mendekati koin (15–23% di bawah 2 tick, sejalan dengan D-147).
Base rate terealisasi dan kalibrasi berbasis label tertinggal h minggu dari perubahan rezim yang mendadak, sehingga memperburuk tepat
pada 2024.

**Kesimpulan D-149.** Dengan split mana pun, tuas sadar-rezim (fitur maupun kalibrasi) tidak menaikkan macro F1 C1-tuned; yang bisa
dilakukan hanya mengoreksi bias proporsi prediksi naik (`R_PO`) bila tujuan pelaporan adalah proporsi arah yang terkalibrasi, dengan
biaya −0,01 macro F1 pada h 8. C1-tuned tetap model terpilih. Sumber kenaikan berikutnya yang tersisa adalah informasi baru yang
mendahului perubahan harga (harga produsen/grosir, pasokan), bukan pengolahan ulang informasi harga & kebijakan yang sudah ada.
